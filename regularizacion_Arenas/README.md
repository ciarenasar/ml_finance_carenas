# regularizacion_Arenas

**Creado**: 2026-06-07  
**Curso**: Machine Learning Aplicado a las Finanzas — USACH

## Descripción

> Regularización aplicada a modelos financieros: Ridge, Lasso, Elastic Net y forecast de volatilidad.

## Reproducción

```bash
git clone <url>
cd regularizacion_Arenas
conda env create -f environment.yml
conda activate regularizacion_arenas
jupyter lab
```

## Estructura

```
data/       → Datos (raw inmutable, processed derivado)
notebooks/  → Exploración y desarrollo
src/        → Código modular reutilizable
models/     → Artefactos serializados + metadata
reports/    → Resultados finales
```
